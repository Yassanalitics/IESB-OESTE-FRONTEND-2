# ✨ Implementação de autenticação mock e melhorias visuais no Chronos Pomodoro

## 📌 O que foi desenvolvido

Nesta atividade foi implementado um fluxo básico de autenticação mock utilizando React Context API, além de melhorias na organização do projeto e modernização da interface visual do sistema.

---

## ✅ Funcionalidades implementadas

### 🔐 Sistema de autenticação mock

* Criação do `AuthContext`
* Implementação das funções:

  * `login`
  * `logout`
  * `isAuthenticated`
* Validação de credenciais mockadas
* Proteção de rotas privadas
* Redirecionamento para login ao sair da aplicação

### 🧾 Página de Login

* Inputs controlados com `useState`
* Manipulação de formulário com `onSubmit`
* Uso de `preventDefault`
* Feedback visual para:

  * login válido
  * login inválido
  * recuperação de senha
  * criação de conta
* Botão para revelar/ocultar senha

### 🎨 Melhorias visuais

* Nova identidade visual com paleta roxa/rosa dark
* Modernização dos botões
* Ajuste visual do contador
* Melhorias no formulário principal
* Ajustes de responsividade e alinhamento
* Atualização do layout geral da aplicação

### ⏱️ Pomodoro

* Ajustes visuais no timer
* Melhorias nos componentes de ciclos e controles
* Atualização da página explicativa da técnica Pomodoro

---

## 🛠️ Tecnologias utilizadas

* React
* TypeScript
* Context API
* CSS Modules
* React Router
* Lucide React

---

## 📚 Observações

A autenticação implementada é apenas simulada (mock), utilizada para fins acadêmicos e prática de conceitos de React, Context API e rotas protegidas.
