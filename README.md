API REST — Projeto Backend
📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma API RESTful utilizando arquitetura backend moderna para realização de operações de cadastro, consulta, atualização e remoção de dados em banco de dados MySQL.

A aplicação foi desenvolvida com foco em:

organização do código;
integração com banco de dados;
criação de rotas HTTP;
manipulação de requisições e respostas;
testes utilizando o Postman;
estruturação de um backend escalável.
🚀 Tecnologias Utilizadas
Node.js
Express.js
MySQL Workbench
MySQL Server
ORM (Sequelize/Prisma)
Postman
JavaScript
dotenv
